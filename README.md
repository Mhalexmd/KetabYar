# کتابیار | Ketabyar

نسخهٔ شخصی مدیریت کتابخانه برای **mhalexmd**، با Java 17، رابط فارسی راست‌چین، SQLite و API محلی.

## امکانات

- مدیریت کتاب و عضو، کنترل شابک و شمارهٔ دانشجویی تکراری
- امانت و بازگشت با حفظ موجودی در تراکنش پایگاه‌داده
- جستجوی فارسی با پشتیبانی از تفاوت «ی/ي»، «ک/ك»، اعراب، نیم‌فاصله و ارقام فارسی، عربی و انگلیسی
- جستجوی چندواژه‌ای در عنوان، نویسنده، شابک و مشخصات عضو
- پذیرش ارقام فارسی و عربی در تعداد نسخه‌های کتاب
- نمایش همهٔ امانت‌ها، امانت‌های فعال، دیرکرددار یا بازگردانده‌شده
- خروجی CSV از ردیف‌های فعلی هر جدول؛ شامل نتیجهٔ جستجو و فیلتر
- CSV با UTF-8 و نشانگر BOM برای نمایش فارسی در Excel و جلوگیری از اجرای متن به‌عنوان فرمول
- رابط کتابیار با رنگ‌بندی سبزآبی و نمایش نام mhalexmd
- رابط HTTP با جستجوی فارسی و فیلتر وضعیت امانت

## اجرای ویندوز

JDK 17 یا جدیدتر لازم است. درایور SQLite در `lib` قرار دارد. فایل **run.bat** را دوبار کلیک کنید.

اسکریپت اجرا ابتدا `JAVA_HOME`، سپس JDK نصب‌شده در مسیرهای معمول ویندوز و در نهایت `PATH` را بررسی می‌کند.

از PowerShell:

```powershell
.\run.ps1
.\run.ps1 -Database 'D:\books\personal.db'
.\run.ps1 -Mode build
.\run.ps1 -Mode test
.\run.ps1 -Mode test -CoreOnly
```

پوشهٔ مقصد پایگاه‌داده باید از قبل وجود داشته باشد. برای اجرای اسکریپت در دستگاهی که اجرای فایل PowerShell محدود است، از `run.bat` استفاده کنید.

## API محلی

```powershell
.\run-api.bat
.\run.ps1 -Mode api -Database library.db -Port 8080
```

API فقط روی `127.0.0.1` در دسترس است. نمونه‌های PowerShell:

```powershell
Invoke-RestMethod 'http://127.0.0.1:8080/api/health'
Invoke-RestMethod 'http://127.0.0.1:8080/api/stats'
Invoke-RestMethod 'http://127.0.0.1:8080/api/books?q=Java'
Invoke-RestMethod 'http://127.0.0.1:8080/api/members?q=123'
Invoke-RestMethod 'http://127.0.0.1:8080/api/loans?status=overdue'
```

| مسیر | متد | کاربرد |
|---|---|---|
| `/` | GET | نام پروژه، مالک و نسخه |
| `/api/health` | GET | سلامت سرویس |
| `/api/stats` | GET | آمار کتابخانه |
| `/api/books?q=...` | GET | فهرست یا جستجوی کتاب |
| `/api/books` | POST | ثبت کتاب |
| `/api/books/{id}` | GET / PUT / DELETE | خواندن، ویرایش یا حذف کتاب |
| `/api/members?q=...` | GET | فهرست یا جستجوی اعضا |
| `/api/members` | POST | ثبت عضو |
| `/api/members/{id}` | GET / PUT / DELETE | خواندن، ویرایش یا حذف عضو |
| `/api/loans?status=all` | GET | فهرست امانت؛ وضعیت‌های all، active، overdue، returned |
| `/api/loans` | POST | ثبت امانت |
| `/api/loans/{id}` | GET | جزئیات امانت |
| `/api/loans/{id}/return` | POST | بازگشت امانت |

بدنهٔ درخواست ثبت کتاب:

```json
{"title":"مهندسی نرم‌افزار","author":"نویسنده","isbn":"SE-001","totalCopies":3}
```

بدنهٔ ثبت عضو:

```json
{"fullName":"علی رضایی","studentNumber":"401001","phone":"09120000000"}
```

بدنهٔ ثبت امانت، با تاریخ امروز یا آینده:

```json
{"bookId":1,"memberId":1,"dueDate":"2026-12-01"}
```

در ویرایش کتاب یا عضو، همان فیلدهای ثبت را ارسال کنید. تاریخ API میلادی و با قالب `yyyy-MM-dd` است. رابط گرافیکی نیز تاریخ میلادی را با قالب `yyyy/MM/dd` نشان می‌دهد.


## داده‌ها و قواعد

- در اولین اجرا `library.db` در پوشهٔ پروژه ساخته می‌شود؛ پایگاه‌داده در شروع خالی است.
- اطلاعات پس از بستن برنامه باقی می‌مانند. برای پشتیبان‌گیری، برنامه را ببندید و فایل پایگاه‌داده را کپی کنید.
- مدت امانت از رابط گرافیکی ۱۴ روز و جریمهٔ هر روز تأخیر ۱۰٬۰۰۰ تومان است.
- بازگشت دوبارهٔ یک امانت رد می‌شود و موجودی را تغییر نمی‌دهد.
- حذف کتاب و عضو دارای سابقهٔ امانت مجاز نیست.
- جستجو متن را فقط برای مقایسه یکسان‌سازی می‌کند؛ دادهٔ ذخیره‌شده را تغییر نمی‌دهد.
- خروجی CSV شامل همان ردیف‌هایی است که پس از جستجو یا فیلتر می‌بینید.
- رابط گرافیکی و API را هم‌زمان روی یک پایگاه‌داده اجرا نکنید؛ این نسخه برای یک اجرای فعال طراحی شده است.

## ساختار

```text
src/main/java/com/example/library/
  AppInfo.java           نام پروژه و مالک
  Main.java              شروع رابط گرافیکی
  ApiMain.java           شروع API
  api/                   HTTP و پردازش JSON
  db/                    اتصال، جدول‌ها و تراکنش‌ها
  model/                 کتاب، عضو و امانت
  repository/            دسترسی پارامتری به SQLite
  service/               قواعد، جستجوی فارسی و فیلتر امانت
  export/                خروجی CSV
  ui/                    پنجرهٔ Swing
src/test/java/            آزمون یکپارچه با دیتابیس موقت
lib/                      وابستگی SQLite JDBC
```

آزمون‌ها دادهٔ موقت مستقل می‌سازند و ثبت، اعتبارسنجی، امانت، بازگشت، تراکنش، ماندگاری داده، API، جستجو و CSV را بررسی می‌کنند. به اطلاعات واقعی پروژه دست نمی‌زنند.

اجرای کامل آزمون‌ها به اتصال داخلی دستگاه نیاز دارد. گزینهٔ `-CoreOnly` در ویندوز یا `--core-only` در Linux/macOS، آزمون‌های داده و منطق برنامه را بدون اتصال شبکه اجرا می‌کند.


## زمینهٔ پروژه

این پروژهٔ مدیریت کتابخانه توسط **mhalexmd** نگهداری می‌شود. مرجع مشترک درس مهندسی نرم‌افزار، طبق معرفی صاحب پروژه، [lintep/se](https://github.com/lintep/se) است.

درایور SQLite JDBC در پوشهٔ `lib` یک وابستگی خارجی است؛ اطلاعات مجوز آن داخل فایل JAR قرار دارد.
